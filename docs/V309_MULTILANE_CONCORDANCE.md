# v309 multi-lane research concordance — evidence review, not identity acceptance

Issue #877 requires an explicit independent review after individual exact-private methods and competing classes have been checked. This command gives that review a **consistent, fail-closed evidence ledger**. It does **not** publish any canonical mapping or accept the 26 blocked fields.

## Required local inputs

Run the existing privacy-bounded research commands against the exact SHA-pinned original v308/v309 JARs, each with a **fresh, distinct output path**:

- #876: complete class field/method-shape report

All reports must be independently generated by their respective gates. **Do not simulate a missing report, assume old javap diagnostic counts are equivalent, or substitute synthetic fixture output as exact-private evidence.**

## Concordance rules

The joiner verifies:

- Tracked class-lineage and global-field files against the SHA-256 values in the accepted frontier.
- Exactly the same pinned v308 and v309 client SHA-256 values in every source.
- Original report IDs and chained provenance, including literal/shape digests for the global-field report, lineage and descriptor-class queue, plus #879's exact parent CP-pair report ID.
- Exactly **eight** canonical old-class IDs accounting for **26** descriptor-blocked field relationships. No duplicate, omitted or reassigned class groups; no invented field identities.
- #881 must show **2,221 / 2,221** pinned structural fingerprints and raw SHA inputs matching, with **zero drift**, including separate 1,129/1,092 build counts. Any drift is a hard stop.
- Every report must be noncanonical, with zero accepted identities and authoritative unresolved count **143**.
- A class may enter the SUPPORTED_SUBSET_ONLY_NEEDS_EXPLICIT_REVIEW *research bucket* only when it has a literal or method-shape contextual witness, at least three unique pairwise CP-bearing method fingerprints, and #879 explicitly reports mutual supported-subset uniqueness across both whole archives. A rival veto, ambiguous/unsupported CP evidence, or incomplete research remains BLOCKED_OR_INSUFFICIENT_NO_ACCEPTANCE.

This is an intentionally conservative **research classification**. It is **not** a permission gate for automatic promotion: matching method shapes, correlated literals, supported method subsequences and absent observed rivals still cannot establish semantic identity conclusively. An independent reviewer must examine all conflicting witnesses and proposed old-to-new identities. Only a separately authored, reviewed, exact-private canonical acceptance process could ever update class or member lineage.
